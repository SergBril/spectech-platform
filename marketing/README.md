# 📢 Маркетинговые материалы SpectechPlatform

## 🎥 Демо-видео

### v2.2.0-chat (Real-time чат по заявке)
**Дата записи:** 21 сентября 2026
**Длительность:** ~3 минуты
**Файл:** `demo-videos/v2.2.0-chat-demo.mp4`

**Сценарий:**
1. Заказчик создаёт заявку "Нужен экскаватор на 3 дня"
2. Владелец видит заявку в маркетплейсе
3. Владелец создаёт отклик с предложением техники
4. Заказчик получает уведомление о новом отклике
5. Открывается чат по заявке
6. Real-time обмен сообщениями между заказчиком и владельцем
7. Заказчик принимает отклик
8. Техника автоматически назначается на заявку

**Использование:**
- Лендинг сайта
- Социальные сети (YouTube, VK, Telegram)
- Презентации для инвесторов
- Обучение новых пользователей

## 🎯 Целевая аудитория

### Владельцы спецтехники
**Боли:**
- Простой техники без заказов
- Сложность поиска клиентов
- Непрозрачные расчёты

**Решение:**
- Публичный каталог с автоматическим подбором
- Прозрачные ставки и условия
- Real-time чат с заказчиками

### Заказчики (строительные компании)
**Боли:**
- Долгий поиск техники
- Ненадёжные поставщики
- Сложность согласования деталей

**Решение:**
- Быстрый поиск через маркетплейс
- Рейтинги и отзывы владельцев
- Мгновенное согласование через чат
