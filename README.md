# 🚜 СпецТехника Про — SaaS-платформа для управления парком спецтехники

[![Version](https://img.shields.io/badge/version-1.6.1-blue)](https://github.com/SergBril/spectech-platform)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![Python](https://img.shields.io/badge/python-3.12-blue)](https://python.org)
[![React](https://img.shields.io/badge/react-18-blue)](https://react.dev)

> Полнофункциональная **multi-tenant SaaS-платформа** для компаний, сдающих в аренду спецтехнику. Управление заявками, GPS-трекинг, учёт топлива, финансовый документооборот и автоматическая генерация PDF-документов с учётом системы налогообложения.

## ✨ Ключевые возможности

### 🏢 Multi-Tenant архитектура
- Полная изоляция данных по компаниям (company_id)
- Переключение между компаниями без перезахода (CompanySwitcher)
- Superuser может работать с несколькими компаниями через `X-Company-Id` header

### 📋 Управление заявками
- Создание и обработка заявок на аренду техники
- Сменные задания и отчёты операторов
- Статусы: новая → в работе → завершена → оплачена

### 🚜 Управление парком
- Каталог спецтехники с типами и характеристиками
- Статусы: свободна / в работе / на ремонте / списана
- Привязка техники к компаниям и заявкам

### 📍 GPS-трекинг и телематика
- Реал-тайм GPS-координаты через WebSocket
- Геозоны с автоматическими алертами
- Учёт моточасов, топлива, скорости
- История треков и статистика

### ⛽ Учёт топлива
- Заправки и сливы с автоматическим определением
- Статистика расхода по технике
- Алерты на подозрительные операции

### 💰 Финансовый документооборот
- Автоматическая генерация счетов, актов, выплат
- **Интеллектуальное налогообложение**: ОСНО / УСН 6% / УСН 15% / Патент / НПД
- Корректный расчёт НДС (включён/сверх)
- Профессиональные PDF с полными реквизитами сторон
- Русификация единиц измерения (час, смена, км)

### 📧 Email-уведомления
- Автоматическая отправка счетов клиентам при создании
- Повторная отправка через кнопку 📧 с PDF-вложением
- MIME-тип `application/pdf` — корректное отображение во всех клиентах
- Уведомления о подписании актов
- Напоминания о просроченных счетах

### 👥 Справочник контрагентов
- Три типа: клиенты, собственники, субподрядчики
- Полные реквизиты: ИНН, КПП, ОГРН, адрес, банк
- Автоматическая подстановка системы налогообложения
- Автозаполнение реквизитов в PDF-документах

### 📊 Аналитика
- Dashboard с ключевыми метриками
- Графики доходов по месяцам (Recharts)
- Статусы счетов (pie chart)
- Топ-5 заявок по сумме
- Тренд доходов за 7 дней (sparkline)

## 🏗️ Технологический стек

### Backend
- **FastAPI** — асинхронный веб-фреймворк
- **PostgreSQL 15** + **SQLAlchemy 2.0** (async)
- **Redis** — кеширование и pub/sub
- **MinIO (S3)** — хранение PDF-документов
- **Pydantic v2** — валидация данных
- **Jinja2** + **WeasyPrint** — генерация PDF
- **MailHog** (dev) / SMTP (prod) — email

### Frontend
- **React 18** + **TypeScript**
- **Vite** — сборщик
- **React Router v6** — роутинг
- **Recharts** — графики
- **TailwindCSS** — стили
- **Axios** — HTTP-клиент
- **Lucide React** — иконки

### Инфраструктура
- **Docker** + **Docker Compose**
- **Nginx** — reverse proxy
- **GitHub Actions** — CI/CD (в разработке)

## 🚀 Быстрый старт

### Требования
- Docker Desktop 24+
- Docker Compose v2
- Git
- Node.js 20+ (для локальной разработки frontend)

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/SergBril/spectech-platform.git
cd spectech-platform

# 2. Скопировать .env
cp backend/.env.example backend/.env
# Отредактировать backend/.env при необходимости

# 3. Запустить все сервисы
docker-compose up -d

# 4. Дождаться готовности (проверка healthcheck)
docker-compose ps

# 5. Открыть в браузере
# Frontend: http://localhost:8080
# Backend API: http://localhost:8000/docs
# MailHog (dev): http://localhost:8025
