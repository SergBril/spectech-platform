# 🚛 СпецТехника Про — Платформа управления спецтехникой

Полноценная веб-платформа для диспетчеризации и управления парком спецтехники.

## 🎯 Возможности

### 🔐 Аутентификация и RBAC
- JWT-аутентификация с refresh-токенами
- 6 ролей: admin, dispatcher, operator, client, owner, mechanic
- 17+ прав доступа с матрицей ролей
- Мультитенантность (изоляция по компаниям)

### 💰 Финансовый модуль (v0.3.0)
- Счета с НДС и позициями
- Акты выполненных работ с двусторонним подписанием
- Выплаты собственникам с авто-расчётом комиссии платформы
- Платежи с автоматическим обновлением статусов
- Финансовый дашборд
- Генерация PDF для всех документов с кириллицей

### 🛰️ Телематика и IoT (v0.4.0)
- GPS-треки в реальном времени
- Геозоны (круги и полигоны) с детекцией входа/выхода
- Учёт топлива (заправки, сливы, детекция аномалий)
- Моточасы и учёт времени работы
- Движок алертов с настраиваемыми правилами (5 типов)
- Уведомления in-app + email (mock)
- Карта OpenStreetMap с маркерами техники

## 🏗️ Технологический стек

### Backend
- **FastAPI** — асинхронный фреймворк
- **SQLAlchemy 2.0** — ORM
- **Pydantic v2** — валидация
- **PostgreSQL** — основная БД (SQLite для тестов)
- **FPDF2** — генерация PDF с кириллицей
- **Pytest** — тестирование (59 тестов)

### Frontend
- **Next.js 14** — React-фреймворк с App Router
- **TypeScript** — типизация
- **Tailwind CSS** — стилизация
- **Leaflet** — карты (без API-ключей)
